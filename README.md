# NYC-311-Analysis
Analyzing NYC 311 service request data to predict response times.

NYC 311: Predicting City Response Times
Why I chose this: Working with NYC data is a challenge because of the sheer scale. I wanted to see if common complaints (like noise or illegal parking) actually had predictable patterns in how fast the city fixed them.

The Process: I used Python and Pandas to clean the data, focusing on calculating "Resolution Hours." I had to handle a lot of missing dates, which taught me that real-world data is rarely as clean as textbook examples!

Key Insight: I found that noise complaints were handled faster than street conditions, which shows how the city prioritizes certain issues.
